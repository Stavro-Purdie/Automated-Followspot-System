1. SYSTEM OVERVIEW
================================================================================
The Automated Followspot System includes a complete beacon management subsystem
for Wi-Fi IR beacons built on Xiao ESP32-C6 hardware. The system provides:

- Real-time telemetry monitoring (battery, current, temperature, fan, LED)
- Remote configuration (brightness, LED enable, fan curves, Wi-Fi, name)
- OTA firmware updates via HTTP
- Multiple GUI interfaces: configurator, live monitor (Shure WWB-style), debug dashboard
- CLI flashing tool with dependency management
- Project-level GitHub-based OTA for the control software itself

Hardware: Xiao ESP32-C6 + SSD1306 OLED + optional INA219 current sensor + fan tach + IR LED

--- Pin Assignments (XIAO ESP32-C6) ---
PIN_IRLED    = 6   // MOSFET gate PWM for IR LED
PIN_VBAT     = 3   // Analog read (voltage divider, 1:1)
PIN_BTN      = 0   // Single push-button (menu navigation)
PIN_SDA      = 4   // I²C SDA
PIN_SCL      = 5   // I²C SCL
PIN_FAN_TACH = 7   // Optional fan tachometer input (2 pulses/rev)

--- Constants ---
BASE_FREQ_HZ   = 30    // Hz for beacon ID 0
FREQ_STEP_HZ   = 5     // Hz per ID step (ID 0=30Hz, ID 1=35Hz, ... ID 15=105Hz)
PULSE_WIDTH_MS = 3     // LED ON time in milliseconds
MAX_ID         = 15    // Maximum beacon ID

--- Battery Calibration ---
VBAT_MAX = 4.20V  // 100% display
VBAT_MIN = 3.40V  // 0% display
VBAT_CUT = 3.35V  // Kill IR LED + warning

--- PWM Brightness Table (0-100% mapped to 6 levels) ---
lvl[] = {0, 32, 64, 128, 192, 255}
lvlIdx = 5  // Default: full brightness

--- NVS Storage (Preferences namespace "beacon") ---
- id     : beaconID (0-15)
- bri    : lvlIdx (0-5)
- ssid   : Wi-Fi SSID
- pass   : Wi-Fi password
- name   : Display name

--- Sensors ---
INA219 (optional): I²C 0x40, 0.1Ω shunt, 32V/2A range
Internal Temp: ESP32-C6 temperatureRead()
Fan RPM: Pin 7 interrupt, 2 pulses/rev, 1-second window

--- Display (SSD1306 128x64) ---
Boot screen → Dashboard (battery, ID, freq, Wi-Fi status, IP, sensors)
Menu screen (hold button 1.5s): Brightness, IR Output, Beacon ID
Warning screens: Low battery, No Wi-Fi (AP mode)

--- Button Logic ---
Short tap in menu: cycle value
Hold 1.5s: enter/exit menu
Auto-exit menu after 6s inactivity

--- Main Loop Timing ---
- Server.handleClient() — non-blocking
- updateSensors() — every loop
- IR pulse driver — micros()-precision at beacon frequency
- Battery sample — every 1000ms
- Display refresh — every 120ms

3. HTTP API ENDPOINTS (Firmware)
================================================================================

All endpoints support CORS (Access-Control-Allow-Origin: *)

----------------------------------------
GET /api/status
----------------------------------------
Returns complete beacon status + telemetry as JSON.

Response:
{
  "id": 1,
  "name": "Beacon-1",
  "brightness_pct": 100,
  "led_enabled": true,
  "battery_v": 12.34,
  "battery_pct": 85,
  "freq_hz": 35.0,
  "uptime_s": 3600,
  "wifi_rssi": -45,
  "wifi_rssi_dbm": -45.0,
  "wifi_ssid": "MyNetwork",
  "current_a": 0.850,
  "temp_c": 42.50,
  "fan_rpm": 2400,
  "last_telemetry": "{}",
  "telemetry": {
    "id": 1,
    "name": "Beacon-1",
    "battery_v": 12.34,
    "battery_pct": 85,
    "current_a": 0.850,
    "fan_rpm": 2400,
    "brightness_pct": 100,
    "temp_c": 42.50,
    "uptime_s": 3600,
    "wifi_rssi_dbm": -45.0,
    "wifi_ssid": "MyNetwork",
    "led_enabled": true
  }
}

----------------------------------------
GET /api/config
----------------------------------------
Returns current configuration (same fields as status).

----------------------------------------
POST /api/config
----------------------------------------
Accepts query-encoded form data:
- id        : beacon ID (0-15)
- brightness: 0-100 (maps to lvlIdx 0-5)
- led       : 1=enable, 0=disable
- name      : display name (max 24 chars, persisted to NVS)

Returns updated status JSON.

Example: curl -X POST "http://192.168.1.50:5000/api/config" -d "brightness=50&led=1&name=Front+Beacon"

----------------------------------------
POST /api/wifi
----------------------------------------
Accepts form data:
- ssid : Wi-Fi SSID (required)
- pass : Wi-Fi password (optional, empty for open)

Stores to NVS, responds {"restart":true}, delays 250ms, ESP.restart().

----------------------------------------
POST /api/telemetry
----------------------------------------
Accepts raw JSON body from control system, stores in lastTelemetryBody.
Returns: {"ok":true,"stored_bytes":N}

----------------------------------------
POST /api/ota
----------------------------------------
Triggers OTA firmware update.

Accepts JSON: {"url": "http://host/firmware.bin"}

Implementation (two handlers exist, second one used):
1. Uses ArduinoJson to parse, then ESPhttpUpdate.update(url)
2. Manual JSON parsing, uses WiFiClient + ESPhttpUpdate.update(client, url)

Response: {"restart":true,"ota_started":true} then async update.

On success: ESP restarts with new firmware.
On failure: Error logged to Serial.

----------------------------------------
OPTIONS /api/*
----------------------------------------
CORS preflight handling: 204 No Content with Allow headers.

--- Constants ---
DEFAULT_TIMEOUT = 2.5  # seconds

--- Helper ---
def build_beacon_url(beacon, path="/api/status") -> str:
    return f"http://{beacon.ip_address}:{beacon.port}{path}"

--- Core Request ---
def _request(url, *, data=None, timeout=DEFAULT_TIMEOUT) -> dict:
    headers = {"Accept": "application/json"}
    if data:
        body = urllib.parse.urlencode(data).encode("utf-8")
        req = urllib.request.Request(url, data=body, headers=headers, method="POST")
    else:
        req = urllib.request.Request(url, headers=headers, method="GET")
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        charset = resp.headers.get_content_charset() or "utf-8"
        return json.loads(resp.read().decode(charset))

    GET /api/status

push_name(beacon, *, name: str, timeout=2.5) -> dict

--- Fan Auto PWM Calculation ---
def _compute_auto_fan_pwm(beacon, temperature_c):
    start, full = beacon.fan_temp_start, beacon.fan_temp_full
    min_pwm, max_pwm = max(0,min(255,beacon.fan_min_pwm)), max(min_pwm,min(255,beacon.fan_max_pwm))
    if full <= start: return max_pwm
    if temperature_c <= start: return min_pwm
    if temperature_c >= full: return max_pwm
    ratio = (temperature_c - start) / (full - start)
    return int(round(min_pwm + ratio * (max_pwm - min_pwm)))

--- Background Polling ---
def _monitoring_loop():
    next_poll_times = {beacon_id: 0.0}
    while monitoring_active:
        now = time.time()
        next_due = now + poll_interval
        for beacon_id, config in beacons_config.items():
            interval = config.get("poll_interval", 1.0)
            due = next_poll_times.get(beacon_id, 0)
            if now >= due:
                status = _poll_beacon(beacon_id, config)
                if status: beacon_status[beacon_id] = status
                next_poll_times[beacon_id] = now + max(0.2, interval)
                next_due = min(next_due, next_poll_times[beacon_id])
        time.sleep(max(0.05, next_due - time.time()))

Usage:
  python3 tools/beacon_flash.py --ssid "MyNet" --password "Secret123" \
      --port /dev/tty.usbmodemXYZ --name "Beacon-1"

Arguments:
  --ssid      : Wi-Fi SSID (required)
  --password  : Wi-Fi password (required)
  --port      : Serial port (required)
  --name      : Display name (default: "Beacon")
  --fqbn      : Arduino FQBN override (default: esp32:esp32:XIAO_ESP32C6)

Workflow:
1. Write wifi_credentials.h to firmware/beacon_wifi/
   #define WIFI_SSID_DEFAULT "MyNet"
   #define WIFI_PASS_DEFAULT "Secret123"
   #define BEACON_NAME_DEFAULT "Beacon-1"
2. Clear Arduino sketch cache
3. arduino-cli compile --fqbn <fqbn> firmware/beacon_wifi
4. arduino-cli upload --fqbn <fqbn> -p <port> firmware/beacon_wifi
5. Clean up wifi_credentials.h

Prerequisites:
- arduino-cli on PATH
- ESP32 core installed (arduino-cli core install esp32:esp32)
- Libraries: Adafruit GFX, Adafruit SSD1306

10. PROJECT-LEVEL OTA UPDATE MANAGER (update_manager.py)
================================================================================

Manages updates for the control software (not beacon firmware).

--- Class: UpdateManager ---
__init__(owner, repo, project_root)
- GitHub API: https://api.github.com/repos/{owner}/{repo}/commits/{ref}
- Archive: https://github.com/{owner}/{repo}/archive/refs/heads/{ref}.zip
- Backup dir: project_root/backups/
- Updates dir: project_root/updates/

--- channel_to_branch(channel) ---
"stable" → "main", "testing" → "testing"

--- check_for_update(branch, last_known_commit=None) ---
Returns:
{
  "branch": branch,
  "latest": CommitInfo(branch, sha, timestamp, url),
  "local_commit": current git SHA,
  "update_available": bool(latest and local and latest.sha != local)
}

--- apply_update(branch, components=None, preserve=None) ---
components: list of top-level paths to install (default: all)
preserve: set of dirs never overwritten (default: {"config","identity_gallery","logs","updates","backups"})

Process:
1. Download ZIP to temp dir
2. Extract
3. Find archive root (repo-branch/)
4. Create timestamped backup dir
5. For each selected path:
   - Skip if first component in preserve set
   - Backup existing to backup dir
   - Copy new files
6. Return {"backup_path": str, "installed_paths": [...]}

--- SSL Handling ---
Tries default context, on cert failure falls back to certifi if installed.
Guides user to install certifi or run "Install Certificates.command" on macOS.

--- Fan Auto PWM Curve ---
def compute_fan_pwm(beacon, temp_c):
    start, full = beacon.fan_temp_start, beacon.fan_temp_full
    min_pwm, max_pwm = beacon.fan_min_pwm, beacon.fan_max_pwm
    if temp_c <= start: return min_pwm
    if temp_c >= full: return max_pwm
    ratio = (temp_c - start) / (full - start)
    return int(min_pwm + ratio * (max_pwm - min_pwm))

16. USAGE INSTRUCTIONS
================================================================================

--- Initial Beacon Setup ---
1. Connect Xiao ESP32-C6 via USB
2. Run flasher:
   python3 tools/beacon_flash.py --ssid "YOUR_WIFI" --password "YOUR_PASS" \
       --port /dev/tty.usbmodemXYZ --name "Beacon-1"
   Or use Launcher → Tools → Flash Beacon (GUI)
3. Beacon boots, connects to Wi-Fi, starts HTTP server on port 5000
4. Note IP address from serial monitor or OLED display

--- Configure Fleet ---
1. Edit config/beacons_config.json with correct IPs
2. Or use Beacon Configurator → Beacon Manager → Add Beacon
3. Set poll_interval per beacon (default 1.0s)

--- Live Monitoring ---
Option A: python3 control/beacon_monitor_gui.py
Option B: Launcher → Tools → Beacon Live Monitor
- View real-time grid of all beacons
- Click Refresh Now for immediate poll
- Export Report for JSON snapshot
- Connection Status for detailed connectivity table

--- Configure Individual Beacon ---
1. Launcher → Tools → Beacon Configurator
2. Select beacon in Live Monitor or Configuration tab
3. Adjust Fan (auto/manual), LED, Power, Network settings
4. Click "Apply Settings to Beacon" → pushes via HTTP

--- OTA Firmware Update ---
1. Host new firmware.bin on HTTP server
2. POST to beacon:
   curl -X POST "http://192.168.1.50:5000/api/ota" \
        -H "Content-Type: application/json" \
        -d '{"url": "http://myserver/firmware.bin"}'
3. Or use Python:
   from control.beacon_network import push_ota
   push_ota(beacon, firmware_url="http://myserver/firmware.bin")

--- Project Software Update ---
1. Launcher auto-checks on startup (configurable)
2. Manual: Launcher → File → Check for Updates
3. Or programmatically:
   from update_manager import UpdateManager
   mgr = UpdateManager("Stavro-Purdie", "Automated-Followspot-System", Path.cwd())
   mgr.check_for_update("main")
   mgr.apply_update("main")

--- Debug Dashboard ---
python3 control/debug_telemetry_dashboard.py
- Simulated 5Hz data for 4 nodes
- Use for UI development without hardware
